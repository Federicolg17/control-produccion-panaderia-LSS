# control-produccion-panaderia-LSS
Aplicación web en Python y Streamlit para el registro de producción y control de mermas en tiempo real, conectada de forma segura a Google Sheets.
#  Sistema de Registro de Producción y Control de Mermas

Aplicación web interactiva desarrollada para la digitalización y captura de datos en tiempo real dentro de una panadería tradicional. El objetivo es eliminar los registros manuales en papel y centralizar la información para análisis operativos.

### 🚀Características
* **Formulario rápido:** Registro de fecha, producto, producción y ventas desde celulares o computadoras.
* **Cálculo de mermas:** Computa automáticamente el porcentaje de pérdida por lote con alertas visuales.
* **Base de datos en la nube:** Guarda todo de forma automática en un archivo de Google Sheets.

### 🛠️ Tecnologías
* Python 3
* Streamlit
* Google Cloud Platform API (Google Sheets)
